# Brewser

Simple Coffee Brewing app.

Go to http://mdelura.github.io/brewser

Enjoy your coffee!

## Development

Requires Node.js 22.12+.

```sh
npm install
npm run dev       # start dev server at http://localhost:5173/brewser/
npm test          # run tests (watch mode)
npm run build     # type-check and build to dist/
npm run preview   # serve the production build locally
```

Pushing to `master` builds and deploys to GitHub Pages via GitHub Actions.
